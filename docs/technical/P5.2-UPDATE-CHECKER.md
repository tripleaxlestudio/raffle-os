# P5.2 Update Checker

Kocokan memeriksa rilis stabil terbaru melalui endpoint publik GitHub Releases:

`GET https://api.github.com/repos/tripleaxlestudio/raffle-os/releases/latest`

Versi aplikasi saat ini tetap berasal dari `package.json` melalui build constant `__KOCOKAN_APP_VERSION__`; tidak ada sumber versi kedua. Respons GitHub divalidasi, hanya rilis non-draft dan non-prerelease yang diterima, lalu versi `major.minor.patch` dibandingkan secara numerik setelah awalan `v` opsional dinormalisasi.

Pemeriksaan menggunakan request tanpa credential dengan timeout lima detik. Offline, timeout, rate limit, respons invalid, dan versi malformed menjadi error nonfatal di Settings tanpa menulis data lokal atau mengganggu fungsi inti Kocokan.

P5.2 hanya menampilkan status dan tautan HTTPS ke halaman rilis. P5.2 tidak mengunduh, memasang, menjalankan, me-restart, atau me-rollback aplikasi.
